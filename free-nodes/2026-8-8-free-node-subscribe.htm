五、策略路由与节点分组的设置详解

小蓝猫Clash的一大亮点在于它的策略路由系统，通过“策略组+规则集”实现灵活的流量管理。

策略组的常见类型：

  • 自动选择（auto）：根据延迟/可用性自动切换最佳节点；

  • 手动切换（select）：用户可在多个节点间自由切换；

  • 故障转移（fallback）：主节点断线后自动连接备选节点；

  • 负载均衡（load-balance）：多个节点平均分配流量，提高效率；

常见规则类型：

  • 国内直连（例如国内常用域名、IP直连）；

  • 国外代理（Google、YouTube、Telegram等走代理）；

  • 游戏优化（Steam、PSN、Xbox 等专线）；

  • 广告屏蔽（自动阻断某些广告域名）；

用户可以根据自身需求，拖放规则顺序，实现细致的网络流量控制。

FAQ

Mellow TUN 模式与 SOCKS5 代理有什么区别？
TUN 模式拦截系统 IP 层流量，实现全局代理；SOCKS5 代理通常只影响指定应用。TUN 更适合全局加速，如游戏、视频和浏览器流量，提高网络稳定性和覆盖范围。
VMess AEAD 加密能防止哪些风险？
AEAD 加密可防止数据篡改、重放攻击和流量特征泄露。在高封锁环境下使用，有助于保持节点长期可用，保证数据安全和连接稳定性。
Netch 如何在 Windows 上加速游戏？
Netch 使用 TUN/TAP 模式将特定进程流量通过代理转发，常用于游戏加速。用户只需将游戏进程添加到列表，选择合适的代理节点，即可降低延迟并绕过地理限制。
QuantumultX 的分流规则支持哪些条件？
支持按域名、IP 地址、端口、请求路径、协议类型或关键词进行分流。结合策略组，可实现广告屏蔽、视频加速、游戏优化等多种自定义网络策略。
Sing-box 的 JSON 配置文件常见语法错误如何快速定位？
通过 JSON 校验工具或编辑器（例如 VSCode）打开配置文件，查看语法高亮与错误提示；也可运行 sing-box 并观察控制台错误信息，错误通常会指出第几行或哪个字段不合法以便修正。
Hiddify Next 如何设置用户带宽限制？
管理员可为每个用户设置独立带宽和流量配额，超出时可自动降速或阻止访问。这样可确保服务器资源合理分配，避免单用户占用过多带宽，提高整体网络效率和公平性。
Clash 的策略组如何提升分流效率？
策略组可以将多个节点或规则组合在一起，实现按条件自动选择最佳节点。通过策略组，用户无需手动切换节点即可根据延迟、地理位置或流量类型自动分流，提高网络效率。
Nekoray 的内置延迟测试为什么与系统 ping 不同？
客户端的延迟测试通常基于 TCP 或特定探测包，而系统 ping 使用 ICMP，两者网络路径与优先级可能不同。此外，防火墙或服务器对 ICMP 的响应可能被限制，导致测试结果存在差异。
Hysteria2 客户端延迟测试值不稳定怎么办？
可通过调整 Hysteria2 的 `recv_window` 与 `send_window` 参数改善传输性能，同时确保服务器带宽充足。若使用移动网络，建议启用 BBR 拥塞控制并降低测速频率以减少波动。
WinXray 的测速功能如何使用？
WinXray 内置节点测速工具，可以通过延迟测试（ping）或带宽测试判断节点质量。用户只需右键节点选择“测速”即可，测试结果将显示在列表中，帮助快速挑选最佳线路。
